title: Setting Up Amenities & Booking Rules
---
The **Amenities & Common Areas** page is where you set up reservable shared spaces — a clubhouse, pool, or pavilion — and manage who uses them. Pick a property at the top of the page, then use **New Area** to add each space.

## Booking rules you can set per area

- **Reservable** — whether residents can book it at all. Non-reservable areas are announce-only.
- **Require approval** — when on, resident requests wait for your approval; when off, requests auto-approve if the time slot is free.
- **Capacity**, **open/close hours** (shown to residents for reference), **max hours per booking**, and **book-ahead limit** (how many days in advance residents can reserve).
- **Max per person per month** — an optional cap on how many reservations one person can make each month.

## Fees

You can set a **reservation fee** and an optional higher **weekend fee** (applied to Friday, Saturday, and Sunday reservations). The fee is billed to the tenant on the platform once the reservation is live. If a reservation is cancelled **48 hours or more** before it starts, the fee is refundable — an unpaid fee is voided, and a paid fee is flagged for you to refund. Cancelled inside 48 hours, the fee stands.

## Private events

Per area, you can allow tenants to book **private events**. Events use a separate **non-refundable event deposit** instead of the reservation fee, and you choose whether the event is announced to the property once paid and whether it auto-releases if unpaid at the start time.

## Holds and decisions

Use **+ Hold** to block an area yourself for a private rental or community event — these go live immediately and can notify every resident that the amenity is unavailable. (Maintenance closures are created from the Maintenance page instead.) Use **Reservations** on each area to approve, decline, or cancel resident requests. Approved reservations are conflict-checked, so two bookings can never overlap in the same window.
